# Part Precision kunddemo

Statisk kunddemo med fysisk och digital broschyr, webbtext, webbpreview och LinkedIn-material.

## Publicering med GitHub Pages

I repots Settings → Pages: välj Deploy from a branch, main och / (root). Sidan publiceras därefter på https://christerholgerssonmissprym.github.io/part-precision/.

Öppna index.html lokalt eller kör en statisk webbserver från denna mapp. Ingen byggprocess krävs. Alla mediefiler finns i repot och länkarna fungerar under /part-precision/.

## Status

Kundmaterial för granskning. Att denna demo publiceras betyder inte att materialet är publicerat på partprecision.se eller LinkedIn. Broschyren för utskrift behöver stämmas av med tryckeriet inför beställning.

Designprofilen bygger på Part Precisions webbplats, granskad 16 oktober 2026. Poppins är primärt typsnitt; Arial är reservtypsnitt där Poppins inte är installerat. Logotyp och foton kommer från Part Precisions webbplats.
